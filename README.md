# Rede Solidária — Protótipo de baixa fidelidade

Protótipo navegável para apresentação acadêmica, feito com HTML, CSS e JavaScript.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).

## O que está incluído
- Área do doador: cadastro demonstrativo, necessidades, intenção de doação e acompanhamento.
- Área administrativa da ONG: painel, necessidades, recebimento, inspeção, estoque, famílias e destinação.
- Layout adaptável para computador e telas menores.
- Dados fictícios e interações simuladas para apresentação.

## Limitações
Não há backend, banco de dados, autenticação real nem persistência. As alterações são temporárias e podem desaparecer ao atualizar a página. O protótipo não deve ser usado para registrar doações reais.
